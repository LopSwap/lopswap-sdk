# Method: createPool()

<kbd>Local</kbd> <kbd>Wallet</kbd> <kbd>HTTP</kbd>

```ts
createPool(params: PreparePoolParams, walletClient: object): Promise<CreatePoolResult>;
```

Prepares, signs, validates, and submits a pool.

This convenience method performs local work, requests wallet signatures,
and sends an HTTP request. It does not send an onchain transaction.

## Parameters

| Parameter      | Type                                                        | Required | Description                                             |
| :------------- | :---------------------------------------------------------- | :------: | :------------------------------------------------------ |
| `params`       | [`PreparePoolParams`](../type-aliases/PreparePoolParams.md) |   Yes    | AMM or flash-loan pool parameters.                      |
| `walletClient` | `object`                                                    |   Yes    | viem wallet client for the pool maker on the SDK chain. |
