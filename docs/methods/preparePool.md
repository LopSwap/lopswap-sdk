# Method: preparePool()

<kbd>Local</kbd>

```ts
preparePool(params: PreparePoolParams): PreparedPool;
```

Builds pool orders and EIP-712 typed data locally.

This method does not use a wallet, RPC, or HTTP. Liquidity amounts must be
provided in token base units. AMM tokens may be supplied in either order;
the SDK sorts them with their amounts by address and applies the onchain
amount encoding.

## Parameters

| Parameter | Type                                                        | Required | Description                        |
| :-------- | :---------------------------------------------------------- | :------: | :--------------------------------- |
| `params`  | [`PreparePoolParams`](../type-aliases/PreparePoolParams.md) |   Yes    | AMM or flash-loan pool parameters. |

### params fields

**`AMM`**

| Parameter             | Type                | Required | Description                                                                                                                       |
| :-------------------- | :------------------ | :------: | :-------------------------------------------------------------------------------------------------------------------------------- |
| `amountA`             | `bigint`            |   Yes    | Actual token A liquidity in its smallest unit, for example `parseUnits('1.5', 6)`. The SDK encodes it as `MAX_UINT256 - amountA`. |
| `amountB`             | `bigint`            |   Yes    | Actual token B liquidity in its smallest unit. The SDK encodes it as `MAX_UINT256 - amountB`.                                     |
| `expiration`          | `bigint`            |   Yes    | Future order expiration as a Unix timestamp in seconds, not milliseconds.                                                         |
| `maker`               | `` `0x${string}` `` |   Yes    | Address that owns and signs the pool orders.                                                                                      |
| `poolNonce`           | `bigint`            |    No    | Optional 72-bit pool nonce. A secure random value is generated by default.                                                        |
| `providerFee`         | `bigint`            |   Yes    | Fee charged by the maker (liquidity provider), in 1/100,000 units. For example, 1_000n is 1%. Valid range: 0n to 65_535n.         |
| `providerFeeReceiver` | `` `0x${string}` `` |    No    | Address that receives the maker's provider fees. Defaults to the maker address.                                                   |
| `tokenA`              | `` `0x${string}` `` |   Yes    | First input token. Tokens may be supplied in either address order.                                                                |
| `tokenB`              | `` `0x${string}` `` |   Yes    | Second input token. Tokens may be supplied in either address order.                                                               |
| `type`                | `"AMM"`             |   Yes    | Selects an AMM pool.                                                                                                              |
